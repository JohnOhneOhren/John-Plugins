# 微信读书笔记 · Codex 插件 0.4.1

选书、时间、导出目标与结果都在 Codex 对话中完成，程序在后台运行，不打开 PowerShell 窗口，也不会要求在终端重复输入书名。需要有本地执行能力的 Codex 和 Python 3.10+；仅云端执行的聊天不能调用这套本地工具。

## 安装与开始

在支持仓库插件市场的 Codex 客户端中添加 https://github.com/JohnOhneOhren/John-Plugins ，安装 weread-notes，然后新开对话：

> 使用微信读书笔记插件，把《不开玩笑》的笔记导入我指定的 Notion 页面，不显示日期。

插件会后台检查 Python 与依赖，必要时在独立虚拟环境安装。选项已在消息中明确就不会重复问。依赖安装或本地访问权限提示仍由 Codex 的权限设置决定，这不要求另开 PowerShell。

## 首次授权，无需终端

1. 插件先检查已有环境变量或本地加密授权。
2. 没有授权时，先独立提示输入 Key，附官方页面 https://weread.qq.com/r/weread-skills 。用户登录后，将自己的 `wrk-` Key 发送到 Codex 对话中。Key 会保留在聊天历史，插件不会假装这是隐藏密码输入框。
3. 插件只回复“已收到 Key，请回复‘确定’继续。”此时不验证、不保存，也不询问书名或其他需求。用户回复“确定”后才在后台验证和加密缓存；取消则不使用。也支持同一条消息发送 Key 并另起一行写“确定”。
4. 授权成功后才显示书架，继续询问选书、Word/Notion、日期和具体位置。已给出且能唯一匹配的书名直接使用，不再去终端输入。

默认不读剪贴板；用户主动要求时仍可选择剪贴板兼容方式。聊天 Key 通过后台进程的 stdin 管道传入，不放进命令行参数或明文临时文件。宿主后台无法传递管道或无本机权限时，会说明限制，不偷偷改为剪贴板或弹出终端。

Windows 下选择记住授权，会用 DPAPI 当前用户保护加密保存到用户数据目录；默认仅加密保留 30 分钟。不同 Windows 用户、不同电脑或不同执行身份可能无法解密，需要重新授权。插件不以明文保存 Key，也不会把 Key 放入命令行。已有 WEREAD_API_KEY 环境变量优先使用。非 Windows 暂不提供加密存储，仍可用预先配置的环境变量；不自动降级为明文存储。

在对话中说“清除微信读书授权”，插件即可删除加密记录；若授权来自环境变量，会提示用户另行清除。Key 过期或失效时重新授权，不循环弹窗。浏览器不需要一直开着，仅登录 Edge 本身不会给插件授权。

Notion 使用当前用户自己的已连接账号；首次按 Codex 的连接流程授权目标页面，不需要在 PowerShell 输入 Integration Token。没有连接时在对话中引导连接，不擅自改用旧终端向导。公共 notion-client API 路径仍留在单文件脚本供开发者独立使用。

## 导出与范围

Word 保存到用户指定的 Weread_Notes_Output 文件夹，在对话中给出文件链接。Notion 计划先保存到本地，再通过用户连接导入；计划含私人笔记，不上传至发布仓库。

Notion 使用普通正文、章节横线、标题后空行，每条摘抄后另留一个真实空段落；“我的想法”“读者观点”挂在对应原文评论中。直接写入页面、子页和数据库记录分别选择；“导入某页”默认为写入正文。公共 API 只能新建块评论，支持选区的连接器可以新建文字选区评论。

点赞观点来自可发现的段落候选及官方单条点赞状态核验，不保证覆盖全书全部点赞。扫描上限或不可见段落可能造成遗漏；失败不假装成没有笔记。

## 读到一半和读完后的再次同步

默认增量同步：读到一半导出一次，读完再导出到同一 Notion 页或同一个 Word 文件时，旧原文和旧评论保留，仅添加新划线、新想法和新点赞观点。已有原文下新增的评论会关联到已有原文，不重复抄录这一段。不同章节分别去重，改变日期显示选项不会把旧记录当成新增。

Notion 会重新读取目标页完整正文和全部评论后再对比。微信读书仍有、但 Notion 目标页已删除的笔记或评论会补回，不再因旧回执标记而跳过；仍存在且能识别的手工改写不会覆盖，定位不清楚时在对话中确认。明确说“保留我在 Notion 的删除状态”才不补回删除项。旧版没有回执的笔记先按同章精确文本匹配。正文或评论读取不完整时暂停，避免把读取失败当作删除。留白也会检查，已有空行不重复叠加。

Word 默认沿用同书上次同步的文件，保留原有排版、手工文字、表格等；写入前保留 .before-sync.bak 备份。多份旧文件或文件移动时，会让你在对话中选择具体文件。明确说“新建一份笔记”才另建文件/页面。默认是只补新增，微信读书端删除笔记或取消点赞不会自动删除已导出的旧内容。

例：“我读完《不开玩笑》了，把新增笔记补到上次那一页，原有内容保留。”完成后会报告保留和新增数量；无新增则不写入目标。

## 升级

升级整个插件及 Skill 需要刷新 Codex 的仓库插件市场并更新安装，新开对话。旧对话可能仍加载旧版本的终端/剪贴板向导说明，必须新开对话使用新版。

运行代码更新器保留 `updates configure/check/apply/rollback`，可由 Codex 后台执行，不需要用户打开终端。自动升级默认关闭，发布者配置真实 release.json 后才可启用。HTTPS 和 SHA256 校验后切换版本，回滚关闭自动更新；不覆盖笔记或授权。更新依赖需完整升级。

微信读书或 Notion 接口变化需要维护者验证、修复并发布新版本，更新器不会凭网页内容自行重写代码。当前尚未配置远端更新源，GitHub 仓库分享不等于公开目录上架。
